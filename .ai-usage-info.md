# MICX Sec VCS SDK
PHP 8.3+, Namespace `Micx\Vcs`. `MixVcs` nimmt einen `RpcTransport`; `RabbitMqTransport` nimmt eine bestehende AMQP-Verbindung. Keine SSH-Schlüssel im SDK. Dateien werden base64-kodiert übertragen. Schreiboperationen prüfen `expectedRevision`. Bei Timeout denselben Request samt ID wiederholen, nie automatisch eine neue ID erzeugen.

Beispiel: [Workflow](examples/workflow.php). Keine globalen Funktionen.
