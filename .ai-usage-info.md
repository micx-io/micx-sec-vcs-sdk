# MICX Sec VCS SDK

PHP 8.3+, Namespace `Micx\Vcs`. `MixVcs` nimmt `RpcTransport`; `RabbitMqTransport` nimmt eine bestehende AMQP-Verbindung. Keine SSH-Schlüssel im SDK.

`checkout` öffnet ein Remote-Repository, `create` erstellt ein leeres lokales Repository mit Remote-URL. `path($workspace)` liefert den Service-Pfad. `update`, `commit`, `push`, `pull` und `merge` benötigen keine Revision/Generation. `commit($workspace)` genügt; Nachricht und kombinierter Push sind optional. Pull/Merge bevorzugen bei Konflikten die eigene Seite und übernehmen konfliktfreie Remote-Änderungen.

`timeout` im Client-Konstruktor: Sekunden, Standard 60, > 0 bis 300. `OperationTimeoutException` erweitert `RpcException` und enthält den vollständigen `request` für Wiederaufnahme mit gleicher ID/Parametern. Timeout ist kein Remote-Rollback. Kein automatischer Reconnect; parallele Prozesse benötigen unabhängige Verbindungen.

Beispiele: [1. Workflow](examples/workflow.php), [2. Repository und Pfad](examples/02-create-repository.php), [3. Konflikte](examples/03-conflicts.php), [4. Timeout](examples/04-timeout.php). Keine globalen Funktionen.
