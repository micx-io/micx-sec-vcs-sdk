# MICX Sec VCS SDK
PHP 8.3+, Namespace `Micx\Vcs`. `MixVcs` nimmt einen `RpcTransport`; `RabbitMqTransport` nimmt eine bestehende AMQP-Verbindung. Keine SSH-Schlüssel im SDK. Dateien werden base64-kodiert übertragen. Schreiboperationen prüfen `expectedRevision` und `expectedGeneration`. Bei Timeout denselben Request samt ID wiederholen, nie automatisch eine neue ID erzeugen.

Beispiel: [Workflow](examples/workflow.php). Keine globalen Funktionen.

`RpcException` erhält Fehlercode, sichere Meldung und Details. Kein automatischer Reconnect: Bei Brokerverlust Verbindung erneuern, unklare Requests mit identischer ID/Parametern wiederholen. Parallelität nur mit unabhängigen Verbindungen pro Prozess. Siehe [Fehlerbehandlung](README.md#fehler-abfangen-und-antworten-zuordnen).
