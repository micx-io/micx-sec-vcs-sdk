# MICX Sec VCS SDK — AI Usage

Dieses SDK trennt Git-Zugriffe von der Anwendung: Der isolierte VCS-Worker
verwahrt den passwortlosen Git-SSH-Key als Secret. Die Anwendung spricht mit
ihm ausschließlich über RabbitMQ und nutzt die ausgecheckten Dateien über
ein gemeinsames Volume. So bleibt der SSH-Key aus den App-Containern heraus.

Für lokale Entwicklung braucht es keinen Git-Worker: Eigene Mock-Verzeichnisse
können direkt im Projekt liegen und unter denselben Repository-URLs registriert
werden. Die Anwendung nutzt in beiden Betriebsarten das gleiche Interface.
Ohne aktivierten Mock-Modus sind ausschließlich Remote-Git-URLs zugelassen.

## Verwendung

```php
const DEVELOPMENT_MODE = true; // In Produktion false setzen.

$manager = new MixVcsManager(
    sharedDirectory: '/vcs-share',
    connector: 'rabbitmq://user:password@rabbitmq:5672/micx.vcs.v1'
);
$manager->addMockDir(
    'git@github.com:example/repo1.git',
    'main',
    __DIR__ . '/mock-repos/repo1'
);

// Mappings dürfen in Produktion im Code bleiben; nur Dev-Modus nutzt sie.
$manager->setAllowMockDir(DEVELOPMENT_MODE);

$repo = $manager->getRepository('git@github.com:example/repo1.git');
$directory = $repo->getDirectory();
```

Das Shared Directory (z. B. `/vcs-share`) muss als vorhandener Mount direkt
unter dem Dateisystem-Root eingebunden sein. Im Worker liegt dasselbe
Volume unter `/data`. Das Mock-Verzeichnis muss ebenfalls bereits existieren.

Der RabbitMQ-Connection-String darf Benutzername und Passwort enthalten,
wenn der Broker nur im abgeschotteten privaten Docker-Netzwerk erreichbar
ist. Zugangsdaten bleiben dennoch geheim und gehören nicht in Git oder Logs.

`getRepository()` erzeugt nur ein Objekt und überträgt keine Daten.
`getDirectory()` nutzt ein vorhandenes Verzeichnis ohne RabbitMQ-Aufruf;
fehlt der Remote-Checkout, wirft es eine Exception. Ein separater Prozess
kann dann `pull()` ausführen. `sync()` führt Pull und Push aus.
`ping(5.0)` prüft die Verbindung; im Mock-Modus antwortet es sofort
mit `true`.

Die Repository-API bietet außerdem `commit()`, `push()`,
`hasUnpushedChanges()`, `getHistory()` und `getBranches()`.
Das vollständige Beispiel steht in
[examples/mixed-repositories.php](examples/mixed-repositories.php).
